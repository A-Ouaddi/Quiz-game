# 🛡️ لعبة الأمان الرقمي - Digital Security Quiz

لعبة تفاعلية لاختبار معرفتك بمبادئ الأمان الرقمي والحماية من المخاطر الإلكترونية.

An interactive quiz game to test your knowledge of digital security principles and protection against electronic risks.

## 🌍 اللغات المدعومة | Supported Languages
- العربية (Arabic)
- الفرنسية (French)
- English (coming soon)

## ⚙️ متطلبات التشغيل | Requirements
- Python 3.x
- مكتبة tkinter (عادة تكون مثبتة مسبقًا مع Python)
- tkinter library (usually comes pre-installed with Python)

## 🚀 كيفية التشغيل | How to Run
### الطريقة الأولى: التنزيل المباشر
1. تأكد من تثبيت Python على جهازك  
   Make sure you have Python installed
2. انسخ ملف البرنامج (`quiz_game.py`)  
   Copy the program file (`quiz_game.py`)
3. افتح نافذة الأوامر (Terminal/CMD) في مجلد الملف  
   Open command window in the file directory
4. اكتب الأمر التالي:  
   Run the following command:
```bash
python quiz_game.py
```

### الطريقة الثانية: عبر GitHub
```bash
git clone https://github.com/A-Ouaddi/Quiz-game.git
cd Quiz-game
python quiz_game.py
```

## 🎮 ميزات اللعبة | Game Features
- واجهة مستخدم جذابة وسهلة الاستخدام  
  Attractive and user-friendly interface
- أسئلة متنوعة في مجال الأمان الرقمي  
  Diverse questions about digital security
- نظام تسجيل النقاط والترتيب  
  Scoring and ranking system
- متعددة اللغات (عربي/فرنسي)  
  Multi-language support (Arabic/French)

## 📊 كيف تعمل اللعبة؟ | How to Play?
1. اختر اللغة المفضلة  
   Choose your preferred language
2. أدخل اسمك  
   Enter your name
3. أجب على الأسئلة التي تظهر لك  
   Answer the questions that appear
4. احصل على تقييمك النهائي  
   Get your final score
5. يمكنك رؤية ترتيبك بين اللاعبين الآخرين  
   See your ranking among other players
